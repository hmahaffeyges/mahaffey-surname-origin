# mahaffey-surname-origin
The documented origin of the Mahaffey surname: Mac Gille Chathbhaidh, son of the servant of Saint Cathbad, from the chapel lands of Kellechaffe at Craigcaffie on Loch Ryan, Galloway. Variants: Mahaffy, Mehaffey, Machaffie, McHaffie, McIlhaffie, Mackilhaffy. Fully sourced, 37 references.
